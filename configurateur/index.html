Bienvenue

Cet outil sert à préparer le contenu d’un site client. Vous remplissez des champs, il fabrique le fichier que le site utilise. Vous n’avez jamais à écrire de code.

Deux façons de commencer :
— Ouvrir un site existant si vous reprenez un site déjà commencé : choisissez son fichier config.json.
— Nouveau site pour partir de zéro.
Important : rien n’est enregistré automatiquement. Quand vous avez fini, cliquez sur Enregistrer le fichier en haut à droite, et transmettez le fichier obtenu.
Ouvrez un site ou créez-en un nouveau pour commencer.
